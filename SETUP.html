⚠️ Icons Missing
This PWA requires app icons to be installed properly. Please add icons before deploying.

Step 1: Create Icons

You need two PNG files in the icons/ folder:

  • icon-192.png - 192x192 pixels
  • icon-512.png - 512x512 pixels

You can:

  • Use an emoji-to-PNG converter with 🏒 or 🥅
  • Create custom icons in design software
  • Use online icon generators like PWA Builder

Step 2: Deploy to GitHub Pages

  1. Initialize git: git init
  2. Add files: git add .
  3. Commit: git commit -m "Initial commit"
  4. Create repo on GitHub
  5. Push: git remote add origin <your-repo-url>
  6. Push: git push -u origin main
  7. Enable GitHub Pages in repo Settings

Step 3: Test Locally

Before deploying, test with:

python3 -m http.server 8000

Then open http://localhost:8000
